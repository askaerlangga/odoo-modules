Advanced Approval Matrix — Stock Inventory Bridge

Seamless integration connecting the generic ae_approval_matrix engine to Odoo's Physical Inventory Adjustments (stock.quant).

ℹ️
Prerequisites Required: This module is an extension bridge and cannot function standalone. It requires both ae_approval_matrix and Odoo's native stock (Inventory) module installed.

Overview

By default, Odoo permits warehouse users to apply physical count adjustments immediately, directly committing valuation changes to the inventory ledger.

ae_approval_matrix_stock introduces strict multi-tier approval governance to physical inventory counts without bloating or modifying the core generic approval framework. It intercepts inventory confirmation actions and ensures every adjustment complies with company authorization rules before stock moves are finalized.

Key Technical Capabilities

  • Strict Apply Guard: Intercepts action_apply_inventory() on stock.quant. Any attempt to commit stock differences without final approval clearance is cleanly blocked.
  • Location View Bypass Protection: Prevents unauthorized modifications in the Location Report view by making inventory_quantity_auto_apply read-only whenever an approval review is active or pending.
  • Context-Aware Auto Apply: When the approval rule is configured with Auto Confirm (action_apply_inventory), the system automatically applies the adjustment the moment the final tier approval is completed.
  • Dedicated Search Filters: Adds intuitive search filters to the Inventory adjustments view: Needs Approval, To My Approval, and Approved.
  • Decoupled Architecture: Follows OCA modular guidelines. The core approval engine remains lightweight and 100% generic for any other business document.

How to Use

  1. Ensure both ae_approval_matrix and stock are installed.
  2. Install ae_approval_matrix_stock.
  3. Navigate to Approval Matrix > Configuration > Approval Matrices.
  4. Create a new matrix setting Target Model to stock.quant (Inventory Adjustment) and define your approval tiers.
